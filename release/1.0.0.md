# ModAVDHostIME v1.0.0

这是 ModAVDHostIME 的第一个独立版本。APK 与 ModAVD 0.36.0 包里的
`components\modavd-ime.apk` 逐字节相同：

- SHA-256：`912c9c9724e63fa606fa5d4e4212cef0e24148b013923ba49d1ebf8cfd38e0e2`
- versionName：`1.0`
- versionCode：`1`
- 签名证书 SHA-256：`d18cca3c1982149349f164d28e02490b2eb694e44d56834fa02a1062eb42e823`

来源包：[ModAVD 0.36.0](https://github.com/ModAVD/ModAVD/releases/tag/v0.36.0)。核对发布 APK 时，
先用一次性 RSA-4096 密钥签 tag 上源码编出的 `aligned.apk`，再运行仓库里的
`scripts/verify_release_apk.py`；它逐字节比较签名块之前的条目区和中央目录，并用 `apksigner` 核对
唯一签名者、v3 验证和证书摘要。

单独使用时：

```sh
adb install modavd-ime.apk
adb shell ime enable org.modavd.ime/.HostImeService
adb shell ime set org.modavd.ime/.HostImeService
```

使用 ModAVD 时，管理器会在开机时按版本号、内容哈希和签名规则自动安装并启用它。
